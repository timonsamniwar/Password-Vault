# Project Statement

## Project Title
Password Generator & Vault

## Problem Statement
People often use weak or repeated passwords and may have difficulty keeping
multiple website/app credentials organized. This project provides a command-line
Python application that generates stronger passwords, checks password strength,
stores website/app credentials in a structured vault, and maintains password
history without displaying the original historical passwords.

## Scope
The project focuses on a local, command-line password management system for
academic demonstration. It supports password generation, strength checking,
vault CRUD operations, search, password history, validation, and local storage.

## Target Users
- Students learning Python programming
- Individual users managing a small set of credentials
- Users who want to practice basic password-security concepts

## High-Level Features
1. Password generation
2. Password strength checking
3. Website/App + Username/Email + Password vault
4. Add, view, search, update and delete operations
5. Password history using SHA-256 hashes
6. Input validation and error handling
7. Local data persistence
